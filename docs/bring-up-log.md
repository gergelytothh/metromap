# Bring-up log

One entry per fault, written as it happens. The best one becomes the
"what went wrong" section of the README and the cover letter.

## Template

### YYYY-MM-DD - short title

- **Symptom:** what you saw
- **Suspected:** what you thought it was
- **Measured / tested:** what you checked, with values
- **Actual cause:** what it turned out to be
- **Fix:** what you changed
